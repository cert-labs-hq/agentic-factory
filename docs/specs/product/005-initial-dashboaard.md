# FRT-001-DASHBOARD-SHELL: Static Factory Visualizer

## 1. Objective
Create a lightweight, single-turn visualization layer to display the AI Factory’s progress and FinOps metrics. This dashboard acts as the "Face of the Factory," consuming the static `index.json` generated by BKP-004 to provide a real-time view of the SDD pipeline's efficiency and output.

## 2. Technical Requirements
- **Stack:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+).
- **Architecture:** Client-side only Single Page Application (SPA).
- **Dependencies:** Zero (no `npm`, no `webpack`, no framework).
- **Data Source:** Fetch API targeting `../.factory/index.json`.

## 3. Functional Specifications

### 3.1 Data Acquisition
1.  **Hydration:** On load, the dashboard fetches the `index.json` from the factory root.
2.  **Validation:** Basic structural check to ensure `metadata` and `slices` keys exist.
3.  **State:** Store the JSON in memory to enable local sorting/filtering without re-fetching.

### 3.2 UI Components (The "FinOps View")
1.  **KPI Cards (Top Ribbon):**
    - **Total Slices:** Count of successfully generated modules.
    - **Token Volume:** Cumulative count of prompt, reasoning, and output tokens.
    - **Shadow Savings:** The `estimated_usd_saved` metric, formatted as USD ($).
2.  **The Registry Table:**
    - A clean, technical list of all slices.
    - Columns: `ID`, `Name`, `Status`, `Tokens`.
    - **Visual Cues:** Status-dependent badges (e.g., Green for `Approved`, Amber for `In Progress`, Red for `Quota-Blocked`).
3.  **Status Distribution:** A simple horizontal percentage bar showing the ratio of completion across the project.

## 4. Architectural Constraints
- **Zero-Dependency:** The dashboard must be a single `index.html` file that runs when served via `python3 -m http.server`.
- **Aesthetic:** "Technical Architect" theme. Dark mode by default, monospace fonts for IDs and token counts.
- **Portability:** The `dashboard/` folder must be self-contained and deployable to GitHub Pages without modification.

## 5. Definition of Done
- `dashboard/index.html` file created and functional.
- Successfully fetches and parses `.factory/index.json`.
- UI renders the "estimated_usd_saved" from the BKP-004 logic.
- Responsive layout that works on both desktop and mobile (for remote monitoring).
- Telemetry entry added to track the visualizer's deployment.
