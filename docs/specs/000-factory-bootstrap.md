# Slice: 000-Factory Bootstrap

## Objective
Establish the initial directory structure and sample files for the Agentic Factory.

## Context
This is the first "slice" of the factory, intended to set up the environment for further spec-driven development.

## Requirements
1. Create the `docs/specs/` directory for technical work orders.
2. Create the `.factory/slices/` directory for metadata tracking.
3. Create the `.github/workflows/` directory for future automation.
4. Provide a sample JSON metadata file and this specification file.

## Acceptance Criteria
- [x] Directories `docs/specs`, `.factory/slices`, and `.github/workflows` exist.
- [x] `.factory/slices/000-factory-bootstrap.json` exists and follows the initial schema.
- [x] `docs/specs/000-factory-bootstrap.md` exists.
